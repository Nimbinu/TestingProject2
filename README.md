# 🧪 Selenium Test Automation Project (Java + TestNG)

This repository contains automated test scripts developed using **Java, Selenium WebDriver, and TestNG** to validate key user flows of the **SauceDemo Web Application**.
The project demonstrates essential Quality Assurance skills, including UI testing, workflow validation, and structured automation development.

---

## 🚀 Project Overview

This automation project covers the following functionalities:

### ✔️ Login Testing

Validates successful login with correct credentials and handles incorrect login attempts.

### ✔️ Add-to-Cart Testing

Confirms that products can be added to the cart and item count updates correctly.

### ✔️ Checkout Flow Testing

Automates filling checkout details and navigating through the purchase flow.

The project is structured using the **Page Object Model (POM)** for clean, reusable, and maintainable test scripts.

## ▶️ How to Run the Tests

### **Option 1: Run through IntelliJ IDEA (Recommended)**

1. Open the project in IntelliJ
2. Go to **testng.xml**
3. Right-click and select **Run 'testng.xml'**

Or run individual tests:
Right-click on any test file → **Run**

---

### **Option 2: Run via Maven (if command line is available)**

```
mvn clean test
```
